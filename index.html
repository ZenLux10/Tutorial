Guida HTML5 per Principianti

Appunti e riferimenti rapidi trasformati in documento web interattivo

1. Struttura Base & Visual Studio Code

In Visual Studio Code (VSC) puoi generare rapidamente lo scheletro di una pagina HTML digitando html:5 e premendo TAB (il tasto a sinistra della lettera "Q").

Risultato del comando:

HTML5 Template 
<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>

Cose da modificare prima di iniziare:

  1. Lingua del documento: Cambia <html lang="en"> in <html lang="it"> per evitare la richiesta di traduzione automatica del browser.
  2. Titolo della scheda: Personalizza <title>Document</title> sostituendo "Document" con il titolo pertinente al tuo progetto.
  3. Collegamento CSS e JS: Per collegare un foglio di stile esterno o script:
    Integrazione File Esterni 
    <!-- Nel <head> per il CSS -->
<link rel="stylesheet" href="assets/css/style.css">

<!-- In fondo al <body> per il JavaScript -->
<script src="assets/js/main.js"></script>

2. Elementi Principali per la Gestione dei Contenuti

Intestazioni (Titoli)

Vanno da <h1> (più importante) ad <h6> (meno importante). Richiedono tag di apertura e chiusura.

Esempio Titolo
<h1>Titolo Grande</h1>

Testo e Contenitori

  • <p>: Definisce un paragrafo di testo.
  • <span>: Contenitore di tipo inline (utilizzato per stilizzare parti limitate di testo).
  • <div>: Contenitore di tipo block per raggruppare vari elementi.

Anatomia di un Paragrafo e Attributi

Anatomia Tag
<!-- Paragrafo semplice -->
<p>Questo Paragrafo</p>

<!-- Link con attributi -->
<a href="https://google.com" target="_blank">Visita Google</a>

Tag Autochiudenti (Self-Closing)

  • <img>: Inserisce un'immagine tramite l'attributo src.
  • <br>: Crea un'interruzione di riga all'interno del testo.
  • <hr>: Inserisce una linea divisoria orizzontale.
  • <input>: Crea campi di input interattivi.
    Tipi di Input
    <input type="text" placeholder="Testo semplice">
<input type="password">
<input type="checkbox">
<input type="submit" value="Invia">

Formattazione Testo

Usa <strong> per il grassetto e <em> per il corsivo.

Formattazione
<strong>Buonasera Gamer!</strong>
<em>Testo in corsivo</em>

4. HTML Semantico

Migliora la struttura della pagina, l'accessibilità e la SEO rendendo chiaro il significato di ciascuna area:

  • <header>: Intestazione della pagina o sezione (logo, menu nav).
  • <nav>: Contenitore riservato ai link di navigazione.
  • <main>: Contenuto principale e unico della pagina.
  • <section>: Sezione generica del documento.
  • <article>: Contenuto autonomo e riutilizzabile (es. post, articoli).
  • <aside>: Barra laterale o contenuti secondari correlati.
  • <footer>: Piè di pagina (copyright, note legali, contatti).
