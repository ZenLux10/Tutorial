1. Cos'è JavaScript e come integrarlo

JavaScript viene eseguito dal motore JS del browser (es. V8 su Chrome, SpiderMonkey su Firefox).

HTML 
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <title>Corso JavaScript</title>
</head>
<body>
  <h1>Messaggio JS</h1>

  <!-- Script esterno (Consigliato) -->
  <script src="script.js" defer></script>
</body>
</html>

2. Variabili e Tipi di Dato

Dichiarazione delle variabili:

  • const: Dichiarazione di costante (valore non riassegnabile). Usa questa di default.
  • let: Dichiarazione di variabile con scope di blocco (riassegnabile).
  • var: Obsoleto. Evita di usarlo a causa dello scope di funzione e dell'hoisting imprevedibile.
JavaScript 
const nome = "Mario"; // Stringa
let eta = 25;         // Numero
const isDeveloper = true; // Boolean

Tipi di Dato Principali:

  1. Primitivi: String, Number, Boolean, Undefined, Null, Symbol, BigInt
  2. Oggetti/Riferimenti: Object, Array, Function
JavaScript 
let datiIncompleti; // undefined
const vuoto = null; // null

3. Operatori e Strutture di Controllo

Comparazione Rigorosa vs Debole: Usa sempre === e !== per evitare la conversione automatica del tipo (type coercion).

JavaScript 
5 == "5";  // true (converte il tipo)
5 === "5"; // false (stretto: confronta tipo e valore)

Condizioni (if, else, switch):

JavaScript 
const ora = 14;
if (ora < 12) {
  console.log("Buongiorno!");
} else if (ora < 18) {
  console.log("Buon pomeriggio!");
} else {
  console.log("Buonasera!");
}

Cicli (for, while, for...of):

JavaScript 
// Ciclo classico
for (let i = 0; i < 5; i++) {
  console.log(`Indice: ${i}`);
}

// Ciclo for...of (per array e iterabili)
const frutti = ["Mela", "Banana", "Pera"];
for (const frutto of frutti) {
  console.log(frutto);
}

4. Funzioni

Le funzioni racchiudono blocchi di codice riutilizzabili.

JavaScript 
// Declarative Function
function somma(a, b) {
  return a + b;
}

// Arrow Function (ES6) - Più sintetica
const moltiplica = (a, b) => a * b;

5. Oggetti e Array

Oggetti (Coppie Chiave-Valore):

JavaScript 
const utente = {
  nome: "Luigi",
  livello: 10,
  saluta() {
    console.log(`Ciao, sono ${this.nome}`);
  }
};

console.log(utente.nome); // "Luigi"
utente.saluta();

Array e Metodi Principali:

JavaScript 
const numeri = [1, 2, 3, 4, 5];

// map: trasforma ogni elemento creando un nuovo array
const doppi = numeri.map(n => n * 2); // [2, 4, 6, 8, 10]

// filter: seleziona solo gli elementi che soddisfano la condizione
const pari = numeri.filter(n => n % 2 === 0); // [2, 4]

// reduce: accumula gli elementi in un unico valore
const sommaTotale = numeri.reduce((acc, curr) => acc + curr, 0); // 15

6. Manipolazione del DOM (Document Object Model)

Il DOM permette a JS di interagire e modificare l'HTML in tempo reale.

Testo originale

HTML & JavaScript 
<!-- HTML -->
<button id="btn">Cliccami</button>
<p id="testo">Testo originale</p>

<!-- JavaScript -->
// Selezionare gli elementi
const bottone = document.querySelector("#btn");
const testo = document.querySelector("#testo");

// Aggiungere un Event Listener
bottone.addEventListener("click", () => {
  testo.textContent = "Il testo è stato modificato!";
  testo.style.color = "#ff79c6";
});

7. JavaScript Asincrono (Promises e Async/Await)

I compiti asincroni (es. recuperare dati da un server) non bloccano l'esecuzione del programma.

JavaScript 
async function ottieniDati() {
  try {
    const risposta = await fetch("https://jsonplaceholder.typicode.com/posts/1");
    if (!risposta.ok) {
      throw new Error(`Errore HTTP: ${risposta.status}`);
    }
    const dati = await risposta.json();
    console.log("Dati ricevuti:", dati);
  } catch (errore) {
    console.error("Si è verificato un errore:", errore);
  }
}

ottieniDati();

8. ES6+ Features Essenziali

Destrutturazione (Destructuring):

JavaScript 
const persona = { nome: "Anna", eta: 30 };
const { nome, eta } = persona; // Estrae variabili direttamente da oggetti

const numeri = [10, 20];
const [primo, secondo] = numeri;

Spread Operator (...):

JavaScript 
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]

const obj1 = { a: 1 };
const obj2 = { ...obj1, b: 2 }; // { a: 1, b: 2 }

Template Literals:

JavaScript 
const prodotto = "Tastiera";
const prezzo = 50;
console.log(`Il costo di ${prodotto} è pari a ${prezzo}€.`);

9. Mappa di Apprendimento Consigliata

  1. Basi: Sintassi, Tipi di dato, Condizionali, Cicli.
  2. DOM & Eventi: Interazione con la pagina web.
  3. JS Moderno (ES6+): Arrow functions, Destructuring, Array Methods (map, filter).
  4. Asincronia: Promises, Fetch API, async/await.
  5. Ecosistema Avanzato: Framework/Librerie (React, Vue) e Server-side JS (Node.js/Express, TypeScript).
