Guida Completa al CSS

CSS (Cascading Style Sheets) è il linguaggio che definisce l'aspetto visivo e la presentazione delle pagine web (colori, layout, font e animazioni).

Indice: 1. Sintassi & Inserimento 2. Selettori & Specificità 3. Box Model 4. Flexbox & Grid 5. Responsive Design 6. Avanzate 7. Metodologie

1. Sintassi Base e Inserimento

Un blocco di regole CSS è composto da un selettore e da un blocco di dichiarazioni racchiuso tra parentesi graffe:

CSS - Sintassi Base 
selettore {
  proprieta: valore;
  proprieta: valore;
}

Come collegare il CSS all'HTML

  1. Esterno (Consigliato): Tramite un file .css separato, collegato nell'head dell'HTML.
    HTML - File Esterno
    <link rel="stylesheet" href="style.css">
  2. Interno: All'interno del tag <style> nella sezione head dell'HTML.
    HTML - Stile Interno
    <style>
  h1 { color: blue; }
</style>
  3. Inline (Sconsigliato): Direttamente sull'attributo style del singolo elemento HTML.
    HTML - Stile Inline
    <h1 style="color: blue;">Titolo</h1>

2. Selettori e Specificità

I selettori determinano a quali elementi HTML applicare le regole di stile.

Selettore Sintassi Esempio CSS Descrizione
Elemento / Tag p p { color: red; } Seleziona tutti i tag <p>.
Classe .nome-classe .btn { background: blue; } Seleziona gli elementi con class="btn".
ID #nome-id #main-header { top: 0; } Seleziona l'elemento unico con id="main-header".
Universale * * { margin: 0; } Seleziona tutti gli elementi del documento.
Attributo [attr] input[type="text"] Seleziona in base al valore di un attributo HTML.

Specificità e Cascata

Quando due o più regole in contrasto colpiscono lo stesso elemento, prevale quella con la specificità più alta secondo questa gerarchia:

  1. Stile style="" inline (priorità massima)
  2. Selettori per #ID
  3. Selettori per .classi, pseudo-classi e attributi
  4. Selettori per tag ed elementi base

3. Il Box Model (Modello a Scatola)

In CSS, ogni elemento HTML è considerato una scatola rettangolare formata da 4 livelli concentrici:

  • Content: Il contenuto reale (testo, immagini, ecc.).
  • Padding: Spazio trasparente attorno al contenuto (interno al bordo).
  • Border: Il bordo che circonda il padding.
  • Margin: Spazio trasparente esterno che separa l'elemento da quelli adiacenti.
CONTENUTO (Testo / Media)
CSS - Box Sizing & Dimensioni 
/* Buona norma per gestire correttamente le dimensioni */
*, *::before, *::after {
  box-sizing: border-box; /* Include padding e bordo nella larghezza totale */
}

.box {
  width: 300px;
  padding: 20px;
  border: 2px solid black;
  margin: 15px;
}

4. Layout Moderno: Flexbox e Grid

Flexbox (Unidimensionale)

Ideale per allineare elementi lungo un singolo asse (righe o colonne), come barre di navigazione e schede.

CSS - Layout Flexbox
.flex-container {
  display: flex;
  justify-content: space-between; /* Allineamento asse principale */
  align-items: center;            /* Allineamento asse trasversale */
  gap: 1rem;                      /* Spazio tra gli elementi */
}

CSS Grid (Bidimensionale)

Ideale per la struttura complessiva della pagina, gestendo contemporaneamente righe e colonne.

CSS - Layout Grid
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); /* Griglia responsive automatica */
  gap: 20px;
}

5. Responsive Design e Media Queries

Consente di adattare l'interfaccia a diversi dispositivi (Mobile, Tablet, Desktop) seguendo la filosofia Mobile-First.

CSS - Media Queries
/* Stili base per Mobile (Approach Mobile-First) */
body {
  font-size: 14px;
}

/* Breakpoint per Tablet e Desktop */
@media (min-width: 768px) {
  body {
    font-size: 16px;
  }
  
  .container {
    display: flex;
  }
}

6. Funzionalità Avanzate

Variabili CSS (Custom Properties)

Permettono di memorizzare valori da riutilizzare in tutto il foglio di stile.

CSS - Custom Properties
:root {
  --primary-color: #3498db;
  --main-padding: 16px;
}

.button {
  background-color: var(--primary-color);
  padding: var(--main-padding);
}

Transizioni e Animazioni

Anteprima interattiva dell'effetto pulse:

Effetto Animato
CSS - Transitions & Keyframes
/* Transizione fluida su un bottone */
.btn {
  background-color: blue;
  transition: background-color 0.3s ease, transform 0.2s ease;
}

.btn:hover {
  background-color: darkblue;
  transform: translateY(-2px);
}

/* Animazione personalizzata Keyframes */
@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.05); }
  100% { transform: scale(1); }
}

.card {
  animation: pulse 2s infinite;
}

7. Metodologia e Moduli Aggiuntivi

  • BEM (Block Element Modifier): Convenzione di nomenclatura per mantenere il codice CSS ordinato e scalabile (es. .card, .card__title, .card--featured).
  • Preprocessori (Sass / SCSS): Estendono il CSS standard introducendo nesting, mixin, variabili avanzate e funzioni matematiche.
  • Framework Utility-First (Tailwind CSS): Permettono di formattare velocemente il layout applicando classi atomiche e predefinite direttamente nell'HTML.
